# Security Wall (온프레미스 보안 점검/차단 솔루션)

40명 규모의 Windows PC를 사용하는 소규모 회사 환경을 기준으로, 복잡한 통합보다는 **보안 경각심을 높이는 체크 프로세스**와 **기본적인 차단/기록**에 초점을 둔 온프레미스형 솔루션의 개요를 정리합니다.

## 목표
- 구성원의 보안 습관을 유도하는 **점검/알림 중심** 프로세스 제공
- 필수적인 위험 행위(USB 사용, 외부 업로드 등)를 **간단히 차단/기록**
- 40대 내외의 PC를 관리할 수 있는 **가벼운 운영 복잡도**

## 주요 기능 범주 (첨부 기능 대응)

### 1) 정보유출 방지
- 이동식 저장매체(USB 등) 사용 차단/허용/기록
- 인터넷 파일 업로드(첨부) 감시 및 정책 기반 차단
- 사용자/시간/대상 파일/행위 기록

### 2) 민감정보 관리
- 문서/폴더 내 민감정보(개인정보, 기밀 키워드 등) 탐지
- 민감정보 포함 파일의 외부 반출 제어
- 민감문서 자동 암호화(정책 기반)

### 3) 웹/소프트웨어 차단
- 사이트 접속 제어(차단/경고/허용)
- 실행 프로그램 제어(차단/경고/허용)
- 정책 예외(업무 필요 앱/도메인) 관리

### 4) 출력물 보안
- 프린터 출력 제한/기록
- 워터마크(사용자명/시간/PC 정보) 삽입

### 5) 문서 백업
- 중요 문서 자동 백업(사내 저장소)
- 유사시 일괄 복구 절차 제공

### 6) PC 취약점 점검
- 간단한 보안 항목(OS 업데이트, 백신 상태, 방화벽, 공유폴더 노출 등) 점검
- 결과 리포트와 개선 권고

### 7) IT 자산 관리
- H/W 지급 이력, 현재 사용 현황
- S/W 라이선스 수량/사용 현황

### 8) 부가 서비스: 설치 유도 서버
- 에이전트 미설치 PC의 인터넷 접속 제한
- 설치 페이지로 유도

## 사용자 흐름 (간단 프로세스)
1. **관리자 설정**: 기본 정책(차단/경고/허용) 템플릿 적용
2. **에이전트 배포**: 40대 PC에 경량 에이전트 설치
3. **일상 점검**: 에이전트가 점검 및 위반 기록
4. **알림/리포트**: 관리자 콘솔에서 요약 리포트 확인
5. **개선 유도**: 사용자 알림/가이드로 행동 개선

## 권장 운영 방식
- 복잡한 DLP 기능보다는 **정책 템플릿 + 위반 기록 + 알림** 중심
- 한눈에 볼 수 있는 **주간 리포트**와 **행동 개선 메시지** 제공
- 불필요한 차단 최소화(업무 영향 최소), 점진적 정책 강화

## 최소 기능(MVP) 제안
- USB 사용 차단/허용/기록
- 웹사이트 접속 제어(차단/경고)
- 프로그램 실행 제어(차단/경고)
- 기본 보안 점검 리포트
- 관리자 콘솔(정책/리포트)

## 시스템 구성(요약)
- **관리 서버**: 정책, 리포트, 에이전트 상태
- **에이전트**: PC 행위 감시 및 정책 적용
- **저장소**: 로그/리포트/백업 파일

## 간단한 프로토타입(정책 평가 CLI)
로컬에서 정책 JSON과 이벤트 JSON을 평가하고 결과를 로그로 남기는 간단한 CLI를 포함합니다.

### 실행 예시
```bash
python -m security_wall.cli --policy config/policy.json --event examples/usb_event.json
```

### 출력 예시
```json
{"action": "usb", "target": "KINGSTON_128GB", "decision": "block"}
```

### 로그 예시
`logs/audit.log`에 JSON 라인 형식으로 기록됩니다.

## GUI 미리보기 (정적 프로토타입)
`ui/index.html`에 관리자 콘솔의 정적 프로토타입 화면이 있습니다.

### 실행 예시
```bash
python -m http.server 8000 --directory ui
```

브라우저에서 `http://localhost:8000` 접속.

## 서버/에이전트 프로토타입 (40대 PC 모니터링 흐름)
40대 PC는 **각 PC에 설치된 에이전트**가 상태(heartbeat)와 이벤트(USB, 웹 업로드 등)를
관리 서버에 전송하고, 서버는 이를 기록/요약하는 구조로 운영합니다.

### 서버 실행
```bash
python -m server.main --host 0.0.0.0 --port 9000
```

### 에이전트(샘플) 실행
```bash
python -m agent.main --server http://127.0.0.1:9000 --agent-id PC-01
```

서버는 `data/events.jsonl`에 이벤트 로그를 남기고 `data/agents.json`에 에이전트 상태를 저장합니다.

## 추후 상세화할 항목
- 정책 룰 구조(우선순위, 예외 처리)
- 민감정보 탐지 규칙(키워드/정규식/샘플 패턴)
- 로그 보존 기간과 감사 대응
- 운영자 역할(관리자/보안 담당/일반 관리자)
